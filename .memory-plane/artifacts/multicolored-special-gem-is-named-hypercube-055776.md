# Multicolored special gem is named hypercube

Use hypercube as the canonical name for Bejeweled's multicolored special game piece (numeric recognizer label 7). 'Multicolor' may describe visual hue evidence but is not the entity name. This corrects prior proposals that called it rotating gem or multicolor cube.
