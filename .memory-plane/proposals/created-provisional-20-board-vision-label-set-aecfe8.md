# Created provisional 20-board vision label set

Selected 20 Pixel 9 Pro boards including three known failures and 17 long-run samples, generated 1,280 normalized cell crops and four coordinate contact sheets, and assigned provisional vision-reviewed ordinary-color labels. The set contains no visibly distinct special gems and includes duplicate repeated-loop states; labels are classifier-seeded and must not be treated as independent ground truth without manual review.
